## 📚 Contenido por parcial

### Primer parcial · Fundamentos y Bootstrap
- **Portafolio personal con Bootstrap**
- Páginas dinámicas y contenido generado con JavaScript
- Elementos y validación de formularios
- Gestión de usuarios guardados como objetos en `localStorage`
- Proyecto final del primer parcial

### Segundo parcial · CSS avanzado y eventos
- Diseño **responsive** con media queries
- Proyecto con más de **250 propiedades CSS** aplicadas y validadas
- Página de inicio estilo red social
- Eventos de formulario con condicionales

### Tercer parcial · JavaScript aplicado
- **5 CRUDs** con tablas dinámicas
- **CRUD de notas con `fetch`**
- Formularios en **modales de Bootstrap** con envío de datos mediante `fetch`
- Formulario de autenticación enviado al servidor
- Operaciones aritméticas y validación con JavaScript

### Actividades en clase
Ejercicios cortos de variables CSS, posicionamiento, contenedores, componentes globales, APIs de HTML5, calculadora con Bootstrap e introducción a JavaScript (en archivos `.zip`).

## 🚀 Cómo verlos

Cada carpeta es un proyecto independiente: basta con abrir su `index.html` en el navegador.
